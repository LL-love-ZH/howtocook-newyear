# 程序员年夜饭 🧨

红红火火的中国年味菜谱网站，精选 18 道年夜饭好菜。

- 菜谱数据来自开源项目 [HowToCook · 程序员在家做饭指南](https://github.com/Anduin2017/HowToCook)
- 纯原生 HTML/CSS/JS 单页应用：挂灯笼、放烟花、贴春联、窗花角饰
- 分类筛选 / 手气上菜 / 完整做法（备料清单、精准用量、分步烹饪、大厨贴士）

在线访问：本仓库的 GitHub Pages 站点。

## 本地预览

```bash
python -m http.server 8734
# 打开 http://127.0.0.1:8734
```
