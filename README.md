# 红红火火家宴菜谱 🧨

373 道家常好菜，红红火火中国年味。看菜谱、点好菜，一键生成年夜饭点菜单。

**在线访问**：https://ll-love-zh.github.io/howtocook-newyear/

## 功能

- 373 道菜全量上架，10 大分类，175 道带成品图
- 实时搜索（菜名 / 食材 / 简介）
- 点菜功能：加入「我的桌」→ 调整份数 → 生成大红纸点菜单（可打印 / 复制分享）
- 年夜饭精选 19 道，每道配好意头标签（年年有余、红红火火…）
- 灯笼、烟花、春联、窗花等中国年元素

## 菜谱来源

内容整理自开源项目 [HowToCook · 程序员做菜指南](https://github.com/Anduin2017/HowToCook)（CC BY-NC-SA）。
